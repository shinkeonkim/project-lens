---
description: 등록된 모든 project-lens 프로젝트를 표로 보여줍니다
---

project-lens 레포 루트에서 `lens`(PATH에 없으면 `<project-lens repo>/.venv/bin/lens`)로
다음을 실행하세요:

```
lens project list
```

출력된 표(slug / visibility / deployment_type / status / updated_at)를 그대로 보여주세요.
등록된 프로젝트가 없다는 안내가 나오면 `/lens-add-project`로 먼저 등록하라고 알려주세요.
